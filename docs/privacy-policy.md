# Privacy policy for WhatsApp Web Improver

Effective date: October 1, 2026

WhatsApp Web Improver is an independent, open-source Chrome extension for improving the WhatsApp Web interface with keyboard shortcuts, message navigation, display preferences and performance controls. It is not affiliated with WhatsApp or Meta.

## Local processing

The extension runs only on `https://web.whatsapp.com/`. It interacts with the visible page locally to identify messages, preserve drafts and activate the native controls requested by the user. It does not upload or persist chats, contacts, message contents, account credentials or authentication tokens. It does not collect browsing history or track activity on other websites.

## Preferences and browser storage

Keyboard shortcuts, navigation preferences and performance settings are stored using Chrome's extension storage. Chrome Sync may synchronize these preferences between the user's browsers when that service is enabled. Display scale and chat-list width are stored locally in the WhatsApp Web browser profile. Temporary memory usage and last-active status are stored locally so the extension dashboard can show whether it is connected.

These stored values do not contain chats, contacts, message contents or login credentials. Removing the extension clears its extension storage; display preferences in WhatsApp Web's local storage can be cleared through that site's browser data settings.

## Network services and sharing

The extension has no developer-operated backend, analytics, advertising or telemetry. It does not sell user data or send it to the developer or third parties. WhatsApp's own features, including messaging and native GIF or sticker pickers, continue to use WhatsApp's services under their applicable policies. Chrome Sync operates under Google's applicable policies.

## User-controlled actions

Message actions use WhatsApp's existing interface and are initiated by the user. Copying a message uses the native copy action and may place that text on the user's clipboard. The extension does not retain clipboard contents. Optional reload controls check for an unsent draft or active call before reloading.

## Contact and changes

Questions about this policy can be raised at [the project's support page](https://github.com/dmrtx/whats-up/issues). The source code is available in [the public repository](https://github.com/dmrtx/whats-up). Changes to this policy will be published here with an updated effective date.
